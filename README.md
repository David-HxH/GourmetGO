## Description:
GourmetGO is a web application that allows users to search for restaurants and view their details. It is built using React for the frontend and Node.js for the backend. The application uses the Yelp API to fetch restaurant data based on user queries.

## Features:
- Search for restaurants by name, location, or cuisine.
- View restaurant details including name, address, phone number, and rating.
- Responsive design for mobile and desktop devices.

## Installation:
1. Clone the repository:
```bashgit clone https://github.com/gourmetgo/gourmetgo.git
```
2. Navigate to the project directory:
```bashcd gourmetgo
```
3. Install dependencies for the backend:
```bashcd backend && npm install
```
4. Install dependencies for the frontend:
```bashcd ../frontend && npm install
```
5. Start the backend server:
```bashcd ../backend && npm start
```
6. Start the frontend development server:
```bashcd ../frontend && npm start
```
